# Time Tracking Dashboard

## Overview
The Time Tracking Dashboard is a responsive web application designed to help users track their time spent on various activities. The dashboard provides a clean and modern interface, adhering to the specified front-end style guide.

## Project Structure
```
time-tracking-dashboard
├── index.html        # Main HTML document
├── styles.css       # CSS styles implementing the style guide
├── script.js        # JavaScript for dynamic functionality
├── README.md        # Project documentation
```

## Features
- Responsive layout for both mobile and desktop views.
- Color scheme based on the specified design guide.
- Typography using the Rubik font for a modern look.
- Interactive elements for tracking time spent on activities.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd time-tracking-dashboard
   ```
3. Open `index.html` in your web browser to view the dashboard.

## Technologies Used
- HTML5
- CSS3
- JavaScript
